# 〈매체로 말해요!〉 — 초등 6학년 국어 매체 수업 실시간 퀴즈쇼 웹앱
> **출처:** 하모쌤

초등 6학년 학생들이 비밀 제시어를 **1라운드(인쇄매체) → 2라운드(음성매체) → 3라운드(영상매체·복합)** 순으로 제작해 교실 TV 퀴즈쇼에서 함께 맞히고, 매체별 전달력을 데이터로 비교하는 웹 애플리케이션입니다.

## 🌐 무설정 실시간 연결 & 방화벽 대응 설계
- **무설정 MQTT-over-WSS 클라우드 중계:** 별도의 DB 주소나 API 키 발급 없이, 교사가 방을 만들면 생성되는 **4자리 방 코드**만으로 유·무선 망 분리 학교에서도 즉시 연결됩니다.
- **중계 브로커 2곳 이중화:** `broker.emqx.io` 연결 실패 또는 지연 시 `broker.hivemq.com`으로 자동 전환됩니다.
- **통신 CDN 이중화 (`jsdelivr` + `unpkg`):** `cdn.jsdelivr.net`에서 `mqtt.min.js`를 우선 로드하고, 차단 시 `unpkg.com`에서 자동 재시도합니다.
- **Web Worker 슬립 방지:** 교사가 다른 탭(예: 유튜브)을 보고 와도 백그라운드 Web Worker가 연결을 깨워두어 방이 잠들지 않습니다.
- **이미지 용량 안전장치:** 캔버스 그림·사진 제출 시 `image/webp` (`0.6`)로 압축하며, 45KB를 넘으면 자동으로 한 번 더 축소해 전송 오류를 방지합니다.

```text
media-quiz-show/
├── index.html       # 시작 / 교사(TV) / 학생(태블릿) 화면 + CDN 이중화 로더
├── css/
│   └── styles.css   # iOS 모노 글래스 UI, 자막·필터·파형 애니메이션

│   ├── sync.js      # 무설정 MQTT-over-WSS 중계(이중화) + Web Worker + 로컬 데모 모드
│   ├── teacher.js   # 교사 TV 호스트 (제시어 관리, 초성 힌트, 컨페티, 비교 대시보드)
│   ├── student.js   # 학생 제작 스튜디오 (금지어 검사, 라운드별 잠금, 5초 미리보기)

└── README.md
```

## 🚀 사용 방법
1. **교실 전체 실시간 수업 (기본값):**
   - `index.html`을 열고 **[교사(TV)로 방 만들기]**를 누릅니다.
   - 학생 태블릿에서도 같은 페이지에 접속해 **4자리 방 코드 + 닉네임**을 입력하면 바로 연결됩니다.
2. **오프라인 / 한 PC 빠른 테스트 (로컬 데모 모드):**
   - 시작 화면 상단의 **[로컬 데모 모드]** 토글을 켜면 인터넷 없이도 같은 PC의 브라우저 탭 간 실시간 테스트가 가능합니다.
   - 교사 대기실의 **[데모 학생 3명 & 전 라운드 샘플 작품 채우기]** 버튼을 누르면 혼자서도 즉시 퀴즈쇼 무대와 대시보드를 시연할 수 있습니다.
